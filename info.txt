Encodes binary data into a Base64-encoded string. It first encodes the binary data using Base64,

oqs library is annoying, refer github for help: https://github.com/open-quantum-safe/liboqs-python

'
git clone --depth=1 https://github.com/open-quantum-safe/liboqs-python
cd liboqs-python
pip install .
